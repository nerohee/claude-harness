# 공개 전 거르기

초안과 이미지를 사용자에게 보이기 전에 본다. 뺀 것 · 바꾼 것은 초안 파일 "거른 것" 에 목록으로 남긴다.

## 빼거나 바꾼다

| 무엇 | 예 | 처리 |
|---|---|---|
| 내 컴퓨터 경로 · 사용자 이름 | `C:\Users\…`, `/home/…`, `\\wsl.localhost\…` | 빼거나 "내 PC" 로 |
| 연락처 | 이메일, 전화, 메신저 아이디 | 뺀다 |
| 비밀값 모양 | 키 · 토큰 · 비밀번호처럼 보이는 문자열 | 뺀다 (이미지에 보이면 그 이미지를 쓰지 않는다) |
| 회사 · 고객 정보 | 회사 이름, 고객, 내부 시스템, 업무 내용 | 뺀다 |
| 비공개 저장소 · 내부 링크 | 공개 안 한 저장소 주소, 로컬 주소 | 뺀다 |
| 남의 자산 | 남의 그림 · 로고 · 화면 (레퍼런스로 본 것) | 쓰지 않는다 — 내 결과물만 |
| 다른 사람 | 실명, 대화 내용 | 뺀다 |

## 물어본다 (빼지 말고 표시)

- **비용 숫자** — "그림 100장에 약 $10" 처럼 흥미로운 숫자는 좋은 재료지만, 공개할지는 사용자가 정한다.
- **아직 발표 안 한 계획** — 출시 시기, 유료화, 다음 프로젝트.
- **실패 · 감정 표현의 수위** — 너무 사적이거나 남 탓으로 읽힐 수 있는 것.

## 이미지에서 볼 것

- 창 제목줄 · 주소창 · 탭 · 파일 경로 · 계정 이름 · 알림이 찍혀 있지 않은가
- 터미널 화면이면 경로 · 사용자 이름 · 환경 변수
- 확대하면 읽히는 작은 글자 (설정 화면, 로그)
