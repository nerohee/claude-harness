# 데스크톱 디자인 — 웹 기준에서 바뀌는 것

`questions-design.md` 를 그대로 따르고, 아래만 바꾼다. 데스크톱 앱은 **오래 켜 두고 반복해서 쓰는 도구** 다 — 첫인상보다 읽기 쉬움 · 밀도 · 키보드가 중요하다.

## 1. 묻는 것

- ★ "주로 휴대폰으로 볼까요, PC 로 볼까요?" 대신 → ★ "주로 어떤 화면에서 쓰나요? — 노트북 / 큰 모니터 / 둘 다"
- 더할 질문 (★ 아님): "한 화면에 많이 보이는 편 / 여유 있게 보이는 편"
- OS 와 비슷한 모양으로 할지는 묻지 않는다 — 기본은 OS 관례를 따르고, 분위기 · 강조색으로 개성을 낸다.

## 2. 제작자가 정하는 것 (questions-design §3 에서 바뀌는 항목)

| 항목 | 웹 기준 | 데스크톱 |
|---|---|---|
| 글자 | 본문 16px 이상, 한글 웹폰트 서브셋 | 본문 13~15px (기본 14px). **시스템 글꼴** — Windows `"Segoe UI", "Malgun Gothic"`, macOS `-apple-system, "Apple SD Gothic Neo"`. 브랜드 글꼴이 꼭 필요하면 앱 안에 넣는다 (오프라인) |
| 배치 | 휴대폰 폭부터 | **최소 창 크기**(`tauri.conf.json` 창의 `minWidth` · `minHeight`)부터, 창을 넓힐 때 자연스럽게. 가로 스크롤 없음 |
| 누르는 대상 | 44px 이상 | 마우스 기준 28~32px 도 된다. 대신 키보드로 전부 쓸 수 있어야 한다 |
| 입력칸 | 16px 이상 (iOS) | 본문 크기와 같게 |
| 다크 모드 | 고객 선택 | 기본은 OS 설정 따라 (`prefers-color-scheme`) |

## 3. 데스크톱에서 더 정하는 것

- **키보드** — 모든 기능을 키보드로. 단축키는 OS 관례(Windows `Ctrl`, macOS `Cmd`)로, 메뉴나 툴팁에 표시한다. 포커스 표시를 지우지 않는다.
- **창** — 제목 표시줄은 OS 기본을 쓴다 (직접 그리면 끌기 · 스냅 · 최대화를 다 만들어야 한다). 창 크기 · 위치는 기억한다 (`window-state`).
- **웹 티 숨기기** — 앱 틀(메뉴 · 버튼 · 사이드바)의 글자 선택과 이미지 끌기를 막는다 (본문 · 입력칸은 그대로). 출시 빌드에서는 브라우저 기본 우클릭 메뉴(새로고침 · 검사)가 보이지 않게 하고, 필요한 곳에만 앱 우클릭 메뉴를 둔다. 버튼 위 커서는 화살표.
- **화면 배율** — 100 · 125 · 150 · 200% 에서 확인한다. 아이콘은 SVG.
- **앱 아이콘** — 작은 크기(16 · 32px)에서도 알아볼 수 있게 단순하게. 트레이 아이콘은 한 가지 색.
- **빈 화면 · 첫 실행** — 데이터가 없을 때 무엇을 하면 되는지 보여 준다.
- **진행 중** — 1초가 넘는 일은 진행 표시, 오래 걸리면 취소 버튼.

## 4. 시안

웹과 같다 (`questions-design.md` §2). 시안은 개발 실행(`npm run tauri dev`)이나 브라우저 화면 모드에서 `?variant=a|b|c` 로 바꿔 본다. 고른 뒤 시안 코드는 지운다.
