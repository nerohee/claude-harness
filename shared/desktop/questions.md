# 데스크톱 앱 질문

묻는 방식은 `questions-dev.md` 와 같다 — 요구사항에 답이 있으면 묻지 않는다. 묻는 형식은 workflow §2 "묻는 형식" — 선택지 A · B · C … + 기타, 권장안을 첫 번째에, 한 묶음 4개까지.

`questions-dev.md` 의 "목적과 사람" · "기능" 표도 함께 쓴다. "운영" 표는 웹 전용이라 이 문서의 "배포와 운영" 이 대신한다.

`항상` = 규모와 상관없이 묻는다, `해당하면` = 요구사항에 그런 기능이 보이거나 앱이 클 때 묻는다.

## 누가 · 어디서

| | 질문 | 왜 묻나 |
|---|---|---|
| 항상 | **누가 쓰나 — 나만 / 아는 사람 몇 명 / 일반 배포** | 서명 · 업데이트 · 비용 · 단계 수가 여기서 갈린다 (아래 표) |
| 항상 | 어느 OS — Windows 만 / Windows + macOS / Linux 도 | 개발 위치 · 빌드 환경 · CI (`stack.md` "개발 환경") |
| 해당하면 | 주로 쓰는 화면 — 노트북 / 큰 모니터 / 둘 다 | 최소 창 크기 · 정보 밀도 |

| 누가 쓰나 | 서명 | 업데이트 | 설치본 |
|---|---|---|---|
| 나만 | 안 함 | 안 함 — 새로 빌드해 다시 설치 | 내 PC 에서 빌드 |
| 아는 사람 몇 명 | 안 함 (첫 실행 경고를 안내) | 업데이트 알림 + GitHub Releases | 대상 OS 별 1종 |
| 일반 배포 | Windows 인증서 · Apple 개발자 계정 (유료, 연 단위) | 자동 업데이트 (서명) | CI 에서 OS 별 빌드 |

## 데이터

| | 질문 | 왜 묻나 |
|---|---|---|
| 항상 | 앱이 다루는 데이터는 무엇이고, 어디에 남아야 하나 — 이 PC 안에만 / 여러 PC 에서 같이 / 서버 | 로컬 DB 인가 서버가 필요한가 |
| 항상 | 인터넷 없이도 돼야 하나 | 오프라인 설계 · 글꼴 · 외부 호출 |
| 해당하면 | 가져올 기존 데이터가 있나 (엑셀, 다른 앱, 폴더) · 내보내기가 필요한가 | 가져오기 · 백업 |
| 해당하면 | 지우면 안 되는 중요한 데이터인가 — 백업이 필요한가 | 자동 백업 · 내보내기 |

## 기능 (OS 와 붙는 것)

| | 질문 | 왜 묻나 |
|---|---|---|
| 해당하면 | 트레이(작업 표시줄 오른쪽 아이콘)에 상주 · 컴퓨터 켤 때 자동 실행 | 창 닫기 동작 · 자동 실행 권한 |
| 해당하면 | 창 하나 / 여러 개 · 닫기 버튼은 종료 / 트레이로 숨기기 · 항상 위 | 창 구조 |
| 해당하면 | 어디서든 누르는 단축키(전역 단축키) · 알림 | 플러그인 · 권한 |
| 해당하면 | 파일을 끌어다 놓기 · 특정 확장자 파일을 이 앱으로 열기 · 링크로 앱 열기(`myapp://`) | 파일 연결 · 딥 링크 · 한 번만 실행 |
| 해당하면 | 외부 서비스 · AI API 를 쓰나 — 키는 누가 내나 | 앱 안에 키를 넣을 수 없다 (아래 위험) |

| | 질문 | 왜 묻나 |
|---|---|---|
| 해당하면 | 업데이트 — 자동 / 알림만 / 수동 (나만 쓰면 묻지 않음) | 업데이트 서명 · 배포 주소 |
| 해당하면 | 월 · 연 비용 상한 (서명 인증서, 서버) | 서명 · 서버 여부 |
| 해당하면 | 언어 (한국어만 / 영어도) | |
| 해당하면 | 접근성 기준 (공공 납품 등) | |
| 항상 | **저장소 공개 여부, 공개라면 `docs/` · 에이전트 설정까지 올릴지** | 공개 저장소 사고 예방 (workflow §6) |

## 제작자가 판단해 먼저 꺼낼 것

요구사항에서 **사용자가 생각하지 못했을 위험**을 찾아 먼저 알린다. "위험 → 제안하는 대응 → 고를 것" 순서로 짧게.

- **앱 안에 넣은 API 키는 누구나 꺼낼 수 있다** → 작은 서버를 두고 거기서 부르거나, 사용자 본인 키를 입력받는다.
- **서명 없이 배포하면** Windows 는 "Windows의 PC 보호" 경고, macOS 는 실행이 막힌다 → 나만 · 아는 사람이면 안내로, 일반 배포면 서명 비용을 계획에.
- **앱 식별자**(`com.<이름>.<앱>`)는 나중에 바꾸면 데이터 폴더와 업데이트가 끊긴다 → P1 에서 정하고 바꾸지 않는다.
- **업데이트 서명 키를 잃어버리면** 이미 설치된 앱을 더는 업데이트할 수 없다 → 저장소 밖에 두고 백업 두 곳.
- **데이터가 PC 한 곳에만 있으면** 고장 · 교체 때 사라진다 → 내보내기 · 자동 백업.
- **WSL 에서 개발하면** 화면이 실제 Windows 와 다르게 보이고 Windows 설치본을 만들 수 없다 → `stack.md` "개발 환경".
- **큰 파일 · 긴 작업**을 화면 쪽에서 하면 창이 멈춘다 → Rust 쪽 비동기 명령으로.
