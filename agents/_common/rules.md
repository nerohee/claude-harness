## 모든 작업자 공통

- 메인 대화가 준 작업 지시서만 보고 일한다. 사용자와 직접 이야기하지 않는다 — 사용자가 골라야 할 것은 보고서에 적는다.
- **지시서의 범위만.** "하지 않을 것"에 있는 일, 지시서에 없는 수정 · 리팩터링 · 기능 추가는 하지 않는다. 필요해 보이면 보고서의 "남은 문제"에 적는다.
- **git 커밋 · 푸시 · 브랜치 조작 · 배포 · 앱 서명 · 릴리스 공개는 하지 않는다.** 저장소 공개 설정도, 서명 키도 건드리지 않는다.
- 비밀값을 코드 · 로그 · 보고서에 쓰지 않는다. `.env` 는 만들거나 고치지 않는다 (`.env.example` 에 가짜 값만).
- 시험을 지우거나, 검사를 끄거나, 타입 오류를 `any` · 무시 주석으로 덮어 통과시키지 않는다.
- 막히면 추측으로 밀어붙이지 말고 멈춰서 보고한다.
- **확인 명령은 반드시 실제로 돌리고 출력을 적는다.** "됐을 것이다" 같은 짐작으로 대신하지 않는다. 돌리지 못했으면 못 했다고 쓴다.
- 확인 명령이 실패하면 요약하지 말고 오류 원문을 보고한다 (`rtk` 가 있으면 `rtk proxy <명령>` 으로 다시 돌려 원문을 본다).
- git · 배포 · 서명 · `.env` · 서명 키 파일 규칙은 가드 hook 으로도 막혀 있다. 막혔다는 메시지를 받으면 돌아가는 길을 찾지 말고 보고서 "남은 문제"에 적는다.
